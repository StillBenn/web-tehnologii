## Лабораторная работа 1 — Food Construct

Главная страница сайта доставки бизнес-ланчей, свёрстанная по макету.

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `styles/style.css` | стили |
| `images/lunch.jpg` | изображение |

## Лабораторная работа 2 — Вёрстка сеток

Страница «Собрать ланч» с меню компании. Сетка блюд построена на Grid,
карточка каждого блюда — на Flex. Обе страницы сайта адаптированы
под планшеты и мобильные устройства.

| Файл | Назначение |
|---|---|
| `lunch.html` | страница «Собрать ланч» |
| `index.html` | главная страница, дополненная адаптивностью |
| `styles/style.css` | общие стили обеих страниц |
| `styles/lunch.css` | стили страницы «Собрать ланч» |
| `images/` | изображения блюд |

Контрольные точки адаптивности: 800px, 600px, 400px.

## Лабораторная работа 3 — Формы и HTTP

Форма заказа на странице «Собрать ланч». Отправляется методом POST
на `https://httpbin.org/post`; все значения полей приходят на сервер.

| Файл | Назначение |
|---|---|
| `lunch.html` | страница «Собрать ланч» с формой заказа |
| `styles/lunch.css` | стили страницы и формы |

Форма разделена на два блока: «Ваш заказ» (селекты блюд и комментарий)
и «Ваши данные» (имя, email, телефон, адрес, время доставки).
Обязательные поля проверяются браузером до отправки.

## Лабораторная работа 4 — Отображение и сортировка блюд

Карточки блюд больше не свёрстаны в HTML: все блюда описаны в массиве объектов,
скрипт сортирует их по алфавиту и создаёт карточки через DOM. По клику на карточку
блюдо попадает в блок «Ваш заказ», стоимость заказа пересчитывается.

| Файл | Назначение |
|---|---|
| `scripts/dishes.js` | массив объектов с блюдами |
| `scripts/script.js` | отрисовка карточек, выбор блюд, подсчёт стоимости |
| `lunch.html` | пустые контейнеры категорий и блок «Ваш заказ» |
| `styles/lunch.css` | стили блока «Ваш заказ» |

## Лабораторная работа 5 — Категории и фильтры

Добавлены категории «Салаты и стартеры» и «Десерты», в каждой категории по шесть
блюд. У каждого блюда появилось свойство `kind`, а над каждой категорией — кнопки-фильтры
с атрибутом `data-kind`. По клику на фильтр в категории остаются только блюда нужного
вида, повторный клик снимает фильтр. Выбор блюд и подсчёт стоимости работают как прежде.

| Файл | Назначение |
|---|---|
| `scripts/dishes.js` | массив из 30 блюд с признаком `kind` |
| `scripts/script.js` | отрисовка, фильтрация, выбор блюд, подсчёт стоимости |
| `lunch.html` | пять категорий с блоками фильтров, блок «Ваш заказ» |
| `styles/lunch.css` | стили фильтров и активной кнопки |
| `images/` | фотографии блюд по категориям |

## Лабораторная работа 6 — Проверка данных и уведомления

Над меню появился блок с доступными для заказа комбо: сетка на три колонки,
каждый комбо и каждое блюдо свёрстаны на флексах, иконки при наведении
поднимаются и увеличиваются через `transform`. При отправке формы скрипт
сравнивает выбранные блюда с пятью вариантами комбо; если набор не подходит,
отправка отменяется и на странице создаётся уведомление о недостающих блюдах.

| Файл | Назначение |
|---|---|
| `scripts/validation.js` | проверка состава заказа при отправке формы, создание и удаление уведомления |
| `lunch.html` | блок «Доступные для заказа комбо» |
| `styles/lunch.css` | сетка комбо, `transform` для иконок, стили уведомления |
| `images/icons/` | иконки блюд |

## Лабораторная работа 7 — Загрузка меню с сервера

Массив блюд убран из кода: функция `loadDishes()` отправляет `fetch`-запрос, получает JSON
и рисует карточки. Внешний вид и все функции страницы прежние. API преподавателя сейчас
недоступен (по объявлению в СДО ЛР 7–9 выполняются через локальное хранилище), поэтому
запрос идёт к файлу `api/dishes.json` в формате API; при восстановлении API меняется только `API_URL`.

| Файл | Назначение |
|---|---|
| `api/dishes.json` | 30 блюд в формате API (`id`, `keyword`, `name`, `price`, `category`, `count`, `image`, `kind`) |
| `scripts/script.js` | `loadDishes()`: fetch, проверка `response.ok`, `response.json()`, обработка ошибок |

## Лабораторная работа 8 — Оформление заказа

Выбранные блюда сохраняются в `localStorage` (только идентификаторы). Новая страница
«Оформить заказ»: состав заказа с кнопками «Удалить» и форма, перенесённая со страницы
«Собрать ланч». На «Собрать ланч» вместо формы — панель со стоимостью и ссылкой
«Перейти к оформлению» (`position: sticky`), ссылка доступна только для заказа, подходящего
под комбо. Заказ сохраняется модулем `orders-api.js`, который выполняет проверки API
(обязательные поля, время доставки, не более 10 заказов).

| Файл | Назначение |
|---|---|
| `order.html`, `scripts/order.js` | страница «Оформить заказ» |
| `scripts/storage.js` | id выбранных блюд в localStorage |
| `scripts/orders-api.js` | сохранение заказа вместо POST /labs/api/orders |
| `scripts/api.js`, `scripts/dish-card.js` | загрузка блюд и карточка блюда — общие для двух страниц |

## Лабораторная работа 9 — Заказы

Страница «Заказы»: таблица заказов (новые сверху) с составом, стоимостью и временем
доставки. Иконки Bootstrap Icons открывают модальные окна `<dialog>`: просмотр,
редактирование (изменяются только разрешённые поля) и подтверждение удаления.
После изменения или удаления — уведомление и обновлённый список.

| Файл | Назначение |
|---|---|
| `orders.html`, `scripts/orders.js` | таблица и три модальных окна |
| `scripts/orders-api.js` | `getOrders`, `changeOrder`, `removeOrder` вместо GET / PUT / DELETE |
| `styles/orders.css` | таблица и модальные окна |

## Лабораторная работа 10 — Лендинг на Bootstrap 5

Страница-лендинг компании, свёрстанная на Bootstrap 5 и его сетке (добавлена к сайту из ЛР9). Четыре блока:
hero с названием, описанием и фотографией; четыре карточки с преимуществами;
тёмный блок с призывом собрать ланч и ссылкой на «Собрать ланч»; форма обратной
связи и контакты. На телефоне меню сворачивается в кнопку, колонки выстраиваются
в один столбец; от 576 px карточки идут по две, от 992 px — по четыре.

| Файл | Назначение |
|---|---|
| `landing.html` | разметка лендинга на классах Bootstrap |
| `styles/landing.css` | шрифт сайта, оранжевый цвет при наведении, размер иконок |
